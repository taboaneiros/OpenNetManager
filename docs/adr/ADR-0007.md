# ADR-0007 — SQLite + PostgreSQL

## Context

O projeto precisa equilibrar onboarding simples com robustez de produção e testes realistas.

## Decision

Adotar SQLite para desenvolvimento local e PostgreSQL para produção e testes principais de integração.

## Consequences

### Positivas

- reduz barreira de entrada para contribuidores;
- mantém banco robusto em produção;
- favorece setup local rápido;
- preserva caminho de evolução sem obrigar infraestrutura pesada local.

### Negativas

- divergências entre engines;
- necessidade de testes em PostgreSQL na CI;
- risco de dependência acidental em permissividades do SQLite.

## Alternatives

### PostgreSQL em todos os ambientes

Maior fidelidade ambiental, porém pior onboarding e setup local.

### SQLite em todos os ambientes

Mais simples, mas inadequado como banco principal de produção para o perfil do projeto.
