# ADR-0006 — Bootstrap

## Context

A Fase 0 precisa de consistência visual, produtividade e componentes administrativos previsíveis, sem gastar energia excessiva construindo um design system exclusivo antes de validar o produto.

## Decision

Adotar Bootstrap 5 como base visual da interface administrativa.

## Consequences

### Positivas

- acelera entrega da UI;
- fornece componentes maduros e bem conhecidos;
- reduz custo de CSS inicial;
- facilita onboarding de contribuidores.

### Negativas

- risco de aparência genérica se usado sem critério;
- limitação relativa frente a design systems totalmente customizados.

## Alternatives

### Design system próprio desde o início

Maior controle visual, porém alto custo de fundação sem retorno imediato.

### Tailwind-only

Flexível, mas exigiria mais decisões de design e composição desde cedo do que o projeto precisa na Fase 0.
