# ADR-0009 — Django REST Framework

## Context

A plataforma precisa expor uma API REST versionada, consistente e alinhada à stack Django adotada.

## Decision

Adotar Django REST Framework como base oficial da API do OpenNetManager.

## Consequences

### Positivas

- integração madura com Django;
- autenticação, permissões e serializers bem estabelecidos.[web:18][web:21]
- suporte nativo a estratégias de versionamento.[web:25]
- grande adoção comunitária e documentação consistente.

### Negativas

- camada adicional de abstração;
- necessidade de disciplina para não misturar serializer com regra de negócio.

## Alternatives

### Django views custom com JSON manual

Mais enxuto inicialmente, porém menos consistente e mais trabalhoso para autenticação, validação e padronização.

### Framework API separado

Aumentaria autonomia da API, mas romperia a simplicidade desejada do monólito modular.
