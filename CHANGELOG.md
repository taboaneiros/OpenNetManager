# Changelog

Este projeto segue, por política, versionamento semântico e registro explícito de mudanças relevantes em formato inspirado em Keep a Changelog.

## [0.1.0] - Fase 0

### Added

- Definição do contexto de produto e engenharia do OpenNetManager.
- Definição da arquitetura em camadas orientada a serviços, repositórios, drivers e parsers.
- Definição da stack base com Python 3.13 e Django 5.2.[web:1][web:3]
- Definição do roadmap macro do projeto.
- Definição de diretrizes iniciais de contribuição, segurança e conduta.
- Estrutura inicial de documentação em raiz e `docs/`.

### Notes

- Esta versão representa documentação fundacional da Fase 0, não uma release funcional de software pronto para produção.
- O suporte inicial ao AP130 é tratado como ponto de partida técnico, não como acoplamento arquitetural permitido.
